# 页签 WebMarker

> 网页标注器 · 给网页打标签、加备注，数据存本地，换浏览器 / 换电脑都不丢。

WebMarker（中文名：页签）是一个基于 Manifest V3 的浏览器扩展（支持 Chrome / Edge，Windows）。它把"网页标注"变成一件简单的事：任意网页打标签分类、加备注，所有数据保存在**你自己选择的本地文件夹**（SQLite 数据库），不依赖任何云端，隐私完全由你掌控。

---

## 1. 项目解决什么问题

- 收藏夹越堆越多，想找某个网页只能靠"猜"？→ **给网页打标签**，按标签秒查。
- 看文章 / 查资料想留个备注，刷新就忘？→ **网页备注**，随时回看。
- 换浏览器、换电脑，收藏和标注就没了？→ **数据存本地文件**，整个文件夹拷走即可，换环境不丢。

## 2. 主要功能

| 功能 | 说明 |
| --- | --- |
| 网页标签分类 | 任意网页一键打标签（支持多个标签），按标签筛选 |
| 网页备注 | 对网页添加备注文字，随时查看修改 |
| 本地数据库存储 | SQLite，数据目录由你自定义；可整体迁移、U 盘备份 |
| 跨浏览器 / 换电脑不丢 | 扩展文件夹 + 数据文件夹整体拷贝即迁移 |
| 管理面板 | 搜索标注（全文）、按标签筛选、单条删除、标签管理 |
| 新标签页 | 网络搜索（百度 / 必应 / 谷歌 / 搜狗）、最近标注、标签墙、背景图 |
| 个性化 | 新标签页背景图（右键随机换 / 恢复默认）、网络搜索框可拖动记忆位置 |
| 明暗主题 | 弹窗与管理面板支持明暗切换 |

## 3. 安装方法（Windows / Chrome 或 Edge）

**前置条件**：Windows 10 / 11；Chrome 或 Edge 浏览器；无需安装其它运行时（本地程序为自包含单文件）。

1. **解压**：把 `WebMarker` 文件夹放到你喜欢的位置（例如 `D:\WebMarker`，路径随意，可整体搬迁）。
2. **加载扩展**：
   - Chrome：打开 `chrome://extensions` → 右上角开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `WebMarker\extension` 文件夹。
   - Edge：打开 `edge://extensions` → 左侧开启「开发人员模式」→「加载解压缩的扩展」→ 选择 `WebMarker\extension` 文件夹。
3. **注册本地程序**：右键 `native-host\auto-register.ps1` →「使用 PowerShell 运行」（或打开 PowerShell 进入该目录执行 `.\auto-register.ps1`）。脚本会自动检测扩展 ID 并注册，看到「注册成功」即可。
   - 若 PowerShell 策略拦截，先执行：`Set-ExecutionPolicy -Scope Process Bypass` 再运行。
4. **数据目录（无需手动选择）**：首次使用会自动使用插件文件夹下的 `WebAnnotatorData`（即 `WebMarker\WebAnnotatorData`），无需手动设置，且随整个插件文件夹迁移。
   - 如需自定义存放路径：点浏览器右上角「页签」图标 → 右上角 ⚙ 按钮 → 输入新路径 →「确认并保存」（原数据会自动迁移到新位置）。

完成。打开任意网页即可标注。

## 4. 使用方法

- **打标签 / 加备注**：打开网页 → 点扩展图标 → 输入标签（多个用逗号分隔）与备注 → 保存。
- **查看与管理**：点扩展图标 →「管理面板」→ 搜索关键词 / 点击标签筛选 / 删除单条标注。
- **新标签页**：
  - 顶部网络搜索框（可切换引擎，按住空白处拖动位置，位置自动记忆）
  - 点左下角 ☰ 进入「标签页」：搜索标注与收藏夹、标签墙（点标签直达管理面板筛选）
  - 右键背景 → 随机换背景 / 恢复默认背景
- **数据迁移（换电脑 / 换浏览器）**：把整个 `WebMarker` 文件夹（含 `WebAnnotatorData` 数据）拷贝到新电脑 → 按第 3 步重新加载扩展并运行注册脚本 → 原有标注、标签、备注全部还在。

## 5. 输入输出示例

**操作示例**

```
用户在网页 https://example.com 上标注：
  标签: 技术, 文档    备注: 这篇讲清楚了缓存原理
→ 保存后在管理面板按「技术」标签筛选即可找到该网页
```

**协议 / API 示例**（扩展与本地程序通过 Native Messaging 通信，帧格式 = 4 字节小端长度 + JSON）

请求（扩展 → 本地程序）：

```json
{"action":"ping"}
{"action":"save","url":"https://example.com","title":"示例页","tags":["技术","文档"],"note":"这篇讲清楚了缓存原理"}
{"action":"search","query":"缓存","limit":20,"offset":0}
{"action":"getTagsWithCount"}
{"action":"deleteAnnotation","id":12}
```

响应（本地程序 → 扩展）：

```json
{"success":true,"data":{"pong":"ok"}}
{"success":true,"data":{"id":12}}
{"success":true,"data":{"results":[...],"total":3}}
{"success":true,"data":{"tags":[{"id":1,"name":"技术","count":5}, ...]}}
{"success":true,"data":{"deleted":1}}
```

## 说明

- 数据保存在本地 SQLite（`webannotator.db`），不在云端，卸载扩展**不会**删除数据。
- 发布包内置**空白数据库模板**（`WebAnnotatorData\webannotator.db`，仅表结构、无任何数据），首次运行选择数据目录后即可直接使用。
- 卸载请运行根目录 `uninstall.ps1`（仅清理注册与配置，数据目录保留）。
